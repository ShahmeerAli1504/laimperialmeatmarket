# La Imperial Meat Market & Taqueria

Bilingual (EN/ES) website for La Imperial Meat Market & Taqueria — Winnemucca, NV.
Two stores: 5184 E Winnemucca Blvd · 1200 S Bridge St.

Static site (HTML/CSS/JS), no build step. Deploy on Vercel with framework preset **Other**.

- `index.html` — home: departments, story, carnicería, taquería, panadería, abarrotes, catering, locations
- `menu.html` — full taqueria menu (served at `/menu`)
- `assets/data.js` — locations, hours, DoorDash link and all menu items/prices (edit here)
- `assets/app.js` — language toggle (Spanish text dictionary), rendering, UI

Built by Nexora Digital.
